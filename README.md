## 흐름 (기획서 3장)

첫 화면(누구나) → 조회 시작 → **로그인·가입**(이메일, 켜져 있으면 구글·카카오) → 약관 동의(처음 한 번) → 팝업에서 조회할 정보 선택(7종 — 2026-10-26 '이름'·'SNS 주소'·'쇼핑몰·사업체명'·'상대가 직접 말한 정보' 뺌) → 한 화면에 하나씩 입력 → 확인(이용자 책임·30일 보관 두 칸) → 13개 항목 결과가 바로 `/report/아이디` → `/my`(내 조회)에서 30일 동안 다시 열기·지우기.

## 오류 안내 원칙 (2026-10-26 오너: 모든 오류에 친절한 쉬운 설명과 안내)

- **화면** — 서버와 주고받는 곳은 모두 `api()`(public/app.js) 하나로. 인터넷 끊김·연결 실패·늦음(504)·너무 큼(413)·JSON 아닌 답·서버 오류를 쉬운 말로 바꾸고, 점검·리포트 열기·문의는 화면에 남는 안내 + '다시 시도'. 설정을 못 받으면 점검 창 대신 안내와 '다시 시도'.
- **입력** — '다음'이 안 눌리면 이유 한 줄(`next.why`). 사진이 아닌 파일·HEIC·너무 큰 사진 안내. 대화 글 2만 자 넘으면 미리 알림.
- **저장이 막힌 브라우저** — 시작은 그대로 되고, 리포트 위에 'PDF로 저장' 안내(`unsaved`).
- **조회 서버가 잠깐 응답하지 않음** — `busy()`(lib/sources.mjs) 로 '무엇을 못 했는지 + 지금 할 수 있는 일(공식 화면 버튼)'. 이런 칸만 남은 항목은 상태 `retry` → '다시 확인 필요', 리포트 '잠시 확인하지 못한 항목' 구역. 키가 없어 못 하는 `pending`(연동 준비 중)과 구분. 공공데이터·국세청 조회는 연결 오류·5xx 한 번 더, 302 는 따라가지 않고 두 번까지 다시.
- **확인할 자료가 없는 칸** — 계좌처럼 자동으로 조회할 공식 자료가 없어 확인한 사실이 0건이면 `clear`(특이사항 없음)가 아니라 `manual` → '직접 확인 필요', 리포트 '직접 확인할 항목' 구역(2026-10-27 — 사기 계좌도 초록 칩으로 읽히던 것). 넣은 값을 되풀이한 문장은 tip.
- **AI 실패** — 캡처 글자 읽기·대화 분석·사진 관찰이 안 되면 무엇을 못 봤는지와 대신 할 일을 알림줄로. 대화 분석은 한 번 다시 묻고(함수 60초 안), 그래도 안 되면 대화 항목 3~7 은 '다시 확인 필요'(규칙으로 대신하지 않는다). 사진 웹 검색 결과는 그대로.
- **없는 주소** — public/404.html (Vercel 이 알아서, PC 서버도 같게).
- 점검: C:/tmp/datecheck-test/err/errors.mjs (BASE·W, 28가지), tests/fallback.test.mjs.

## 이용 구조 (2026-10-27 오너: 결제·통신판매 없이, 로그인해야 모든 기능)

- **결제 없음.** 예전 무료 점검/정밀 분석(가격 시험)·신고용 정리본·재검사 상품을 모두 없앴다. 로그인한 회원은 13개 항목, 대화 순서 정리, 다음에 할 일, 신고용 정리본을 그대로 본다. `/api/pay` 없음.
- **로그인해야 모든 기능**: 조회(`/api/analyze`)·리포트(`/api/report`)·내 조회(`/api/reports`)·지우기. 첫 화면·안내 페이지·예시 리포트·약관·문의는 누구나.
- **조회 대상은 '나'**: 화면은 '내 정보나 내가 받은 정보'로 안내하고, 조회할 때마다 이용자 책임 확인(입력한 정보는 제 정보이거나 제가 받은 정보 · 다른 사람을 괴롭히거나 퍼뜨리는 데 쓰지 않음 · 입력과 이용의 책임은 저에게)을 받는다. 서버도 `attest: true` 가 없으면 받지 않는다. 약관 제4·5조(`content/legal.mjs`).
- **로그인**: Supabase Auth 를 우리 서버가 대신 부른다(브라우저에 키·라이브러리 없음). 토큰은 httpOnly 쿠키(`dc_at` 1시간, `dc_rt` 30일, SameSite=Lax·Secure) — 만료되면 서버가 갱신 토큰으로 바꿔 준다(`lib/auth.mjs`). 다른 사이트에서 온 POST(Origin 다름)는 거절. 구글·카카오는 PKCE(`/api/auth/oauth` → Supabase → `/api/auth/callback`), Supabase 에서 켜면 버튼이 자동으로 나온다(`/api/config` auth). 메일 링크(가입 확인·비밀번호 재설정)는 token_hash 로 `/api/auth/confirm` — 다른 기기에서 열어도 된다.
- **약관 동의**: 만 14세 이상·이용약관·개인정보 수집·이용(세 칸 필수) — 가입할 때, 소셜 로그인은 처음 들어올 때 동의 창. 판은 `CONSENT_VERSION`(lib/auth.mjs) — 약관을 바꾸면 날짜를 올리면 모두 다시 동의한다.
- **계정 한도**: 10분 10번·24시간 30번(`QUOTA`, 데이터베이스 `take_quota` 가 계정·종류별로 잠그고 센다). 접속 주소 한도(`LIMITS`)는 1차 방어.
- **메일 발송**: 지금은 Supabase 기본 메일(우리 팀 주소로만 감)이라 `mailer_autoconfirm` 을 켜 둠(메일 확인 없이 가입). 비밀번호 찾기 메일을 쓰려면 SMTP(예: Gmail 앱 비밀번호, Resend)를 Supabase 에 붙이고 autoconfirm 을 끈다.
- Supabase 설정을 다시 넣는 도구: `C:/tmp/dc-auth`(auth-config.mjs — 사이트 주소·돌아올 주소·한국어 메일, sql.mjs — `db/schema.sql` 적용).

## SNS 계정·이름은 받지 않는다 (2026-10-26 오너)

- 이름과 SNS 계정은 특정한 사람을 가리키는 정보라 받지 않는다(사람 찾기로 보이지 않게, 개인정보 최소 수집). 예전 화면이 보내도 `cleanInput` 이 버린다.
- 링크 칸·대화에 섞인 SNS·유튜브·블로그 주소는 `isSnsUrl`(public/parse-input.js)로 걸러 확인하지 않는다. 화면은 링크 칸에 SNS 주소만 넣으면 이유를 알리고 다음을 막는다.
- 사진 웹 검색에서 SNS 계정 페이지는 주소·제목(이름·아이디가 들어 있음)을 보여 주지 않고 개수만 — 상대 본인 계정이면 사람 찾기가 된다. 사진 관찰 AI 는 남의 계정 아이디를 옮겨 적지 않는다(프롬프트 + 서버에서 @아이디 가림).
- 전화번호·계좌번호 네이버 버튼은 '"번호" 사기'로 — 번호만 검색하면 그 사람에 관한 글이 다 나온다.
- 회사 입력: (주)·㈜·주식회사·Co., Ltd. 와 '다녀요·에서 일해요·대표' 같은 뒷말을 떼고 찾는다(companyName). 이름 비교는 nameKey.

- 대화 단계 탭 셋: 캡처 올리기 · **카톡 파일** · 글로 붙여넣기. 카톡 파일은 `public/kakao-export.js` 가 **브라우저 안에서** 읽어, 고른 사람은 '나:' 나머지는 '상대:' 줄로 바꾼 글(chatText)만 서버로 보낸다. 이름과 파일은 서버로 가지 않는다.

- '나' 정하기: 휴대폰 파일의 '회원님', 1:1 대화면 제목('○○ 님과 카카오톡 대화')의 반대편. 단체방·제목 없는 파일은 이용자가 고른다('이 중에 나는 없어요' = 모두 상대).

- 길면 **최근 메시지부터** 1만 9,500자까지(서버가 2만 자에서 자름). 화면에 몇 개·어느 날부터인지 알린다.
- 글로 붙여넣기에 카톡 PC 에서 복사한 글을 넣으면 같은 바꾸기를 권한다.

## 직접 조회 안내(경찰민원24·더치트)

- 두 곳은 API·제휴가 없어 이용자가 직접 찾는다. 리포트 전화번호·계좌번호 항목에 '직접 조회해 보세요' 칸(큰 버튼 2개 + 복사 칸) → 버튼을 누르면 순서 안내, 복사 칸, 화면 캡처(사이트 맨 위부터 검색 칸까지, 검색 칸에 빨간 상자. 누르면 새 페이지 없이 팝업으로 크게 — 처음엔 빨간 상자 쪽으로 맞추고, 폰의 가로 그림은 옆으로 밀어 봄. 맞출 곳은 sizes.json 의 focus), 캡처 밑에 사이트 링크.
- 복사 칸(`copyField`): 번호 + 복사 버튼, 누르면 2초간 '복사됨'. 클립보드가 막히면 번호를 선택해 둔다. 번호 글자에는 줄바꿈용 붙임 글자를 넣지 않는다(직접 끌어 복사해도 깨끗하게).
- 캡처: `public/img/howto/` — PC용 `police-phone·police-account·thecheat.webp`, 폰용(폭 600px 이하) `*-m.webp`, 크기는 `sizes.json`. 경찰민원24 폰용은 실제 모바일 화면 맨 위부터 조회 칸까지, 더치트 폰용은 PC 화면을 폰 폭에 맞게 자르고 선·꼬리표를 크게(더치트 모바일 화면은 자동 브라우저에서 열리지 않음).
- 사이트 화면이 바뀌면 다시 찍기: `SHARP_PATH=… PLAYWRIGHT_PATH=… node scripts/howto-shots.mjs`. 찍은 뒤 빨간 상자 위치를 눈으로 확인하고, 크기가 바뀌었으면 `public/app.js` 의 `HOWTO` size·sizeM 을 `sizes.json` 대로 맞출 것.
- 링크 정의는 `lib/links.mjs` 의 `guide` 표시, 화면 문구는 `public/app.js` 의 `HOWTO`.

## 개인정보 (기획서 8장)

- 원본(번호·사진·대화)은 분석이 끝나면 서버에서 버린다. 디스크에 쓰지 않는다.
- 리포트에서 넣은 정보를 다시 볼 수 있게(카드 제목 옆 '사진 보기'·'대화 보기' 등, 2026-10-26 오너) 화면이 조회 직후 원본을 **조회한 기기의 IndexedDB**(datecheck/inputs)에 24시간 둔다. 서버로는 다시 보내지 않는다. '이 기록 지우기'로 계정 기록과 함께 바로 지운다.
- 예시 리포트 `/report/example` = public/example-report.json(대화 43줄·번호 010-0000-0000 은 꾸민 자료, 사진은 사기에 자주 도용되는 유명인 사진의 예로 키아누 리브스 — 위키미디어 공용 CC BY-SA 4.0, Marybel Le Pape. 출처는 사진 창에 링크로, 안내 문구는 json note. 2026-10-26 오너가 연예인 사진으로 결정(초상권·퍼블리시티권 위험 안내 뒤)). 다시 만들 때는 C:/tmp/datecheck-test/full/capture.mjs → make-example.mjs.
- 조회 결과는 서버만 풀 수 있는 암호화 봉투(lib/token.mjs, AES-256-GCM)로 만들어 **내 계정**(Supabase `reports.sealed`)에 30일 둔다. 데이터베이스에는 봉투와 목록용 숫자(검사한 항목·신호 수)만 — 데이터베이스가 새어도 내용은 안 보인다. 다른 계정으로는 안 열린다(행의 user_id 와 봉투 안 user 를 둘 다 본다). 30일이 지나면 pg_cron 이 매시간 지운다.
- 회원 탈퇴(`/my` → 회원 탈퇴)하면 Supabase 회원을 지우고, 조회 기록·동의·횟수 기록이 함께 지워진다(on delete cascade).
- 삭제 요청·문의는 로그인 없이도 받는다 — 내 번호가 남의 조회 기록에 있을 것 같은 사람(회원 아님)도 요청할 수 있게. 데이터베이스 `requests`.
- `data/`(PC)·임시 폴더(Vercel)에는 개인정보 없는 화면 이벤트·API 호출 비용·관리자 접근 로그만 남는다.

## Vercel 배포

- 구조: 화면 파일은 `public/` 을 그대로 내보내고, `/api/*` 는 `api/index.mjs` 함수 하나가 받는다(`vercel.json` rewrites, 최대 60초). 처리 코드는 PC 서버와 같은 `lib/app.mjs`.
- PC 서버 파일 이름을 `server.mjs` 로 두면 Vercel 이 서버로 잘못 잡으므로 `dev.mjs` 로 둔다.
- Vercel 프로젝트 설정 → Environment Variables 에 넣을 것: `GEMINI_API_KEY`, `GEMINI_MODEL`, `ADMIN_KEY`, `REPORT_SECRET`(긴 임의 문자열 — ★운영에서 없으면 점검이 멈춘다, 대체값 안 씀), `DATA_GO_KR_KEY`, `GOOGLE_VISION_API_KEY`. 네이버 키는 2026-10-22 네이버 검색 API 를 뺀 뒤 쓰지 않는다. 제미나이 키가 없으면 대화 항목은 '연동 준비 중'으로 나온다(규칙으로 대신 판별하지 않는다).
- **보안·남용 막기(2026-10-27)** — `vercel.json` 이 모든 응답에 CSP(스크립트는 자기 사이트만, 글꼴은 jsdelivr, 사진은 data·blob)·X-Frame-Options DENY·nosniff·Referrer-Policy·Permissions-Policy. 횟수 제한 `LIMITS`(lib/app.mjs): 점검 같은 접속 주소 10분 12번·하루 60번, 문의 한 시간 5번, 관리자 키 틀림 15분 10번 — 함수 인스턴스마다 세는 1차 방어(영구 저장소를 붙이면 그쪽으로). 화면이 보내는 이벤트는 `CLIENT_EVENTS` 만 받는다(결제·매출 이벤트는 서버만). AI 지시문은 systemInstruction, 대화·캡처·사진은 자료로만(프롬프트 주입 막기).
- 구글 서치콘솔: index.html 의 google-site-verification 메타는 자동화 계정(winaid-automation) 소유 확인용 — 지우면 소유권이 풀린다.
- 요청 크기 한도 4.5MB — 화면이 캡처를 긴 변 1600px 로 줄이고, 넘으면 미리 막는다.
- 회원·조회 기록·동의·계정 한도·문의는 Supabase(서울)에 남는다. 화면 이벤트·API 비용 집계와 관리자 로그만 임시 폴더(/tmp)라 함수가 다시 시작되면 사라진다.
